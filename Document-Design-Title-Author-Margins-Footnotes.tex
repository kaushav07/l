\section{Introduction}
This is my first practical of \LaTeX{}. Here I have chosen the title, author name, date and address of the document.\footnote{The address is written inside the author command using double backslash.}
The page size is A4 and the margins are set using the geometry package.

\section{Line Spacing}
\onehalfspacing
This paragraph is typed with one and a half line spacing. Line spacing can be changed using the setspace package. It makes the document easy to read, and teachers also like it for assignments.\footnote{Other options are \texttt{\textbackslash singlespacing} and \texttt{\textbackslash doublespacing}.}

\doublespacing
This paragraph is typed with double line spacing. Notice that the lines are now far from each other compared to the earlier paragraph.

\singlespacing
\section{Page Orientation}
By default the page is in portrait mode. For landscape orientation we can write \texttt{landscape} in the options of geometry, for example \texttt{\textbackslash usepackage[landscape]\{geometry\}}.\footnote{Landscape means the page is wider than it is tall.}

\section{Conclusion}
In this practical I learnt how to set the title, author, date, margins, line spacing and footnotes in \LaTeX{}.
